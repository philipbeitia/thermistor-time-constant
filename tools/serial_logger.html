  1. Connect — pick the Arduino in the pop-up (it's the only "Arduino"/"USB Serial" entry). The board resets; numbers start arriving.
  2. Sensor in air, hands off. Type the file name (bare_run1 … sleeved_run3).
  3. Start run — wait ~15 s for a flat line, then read the thermometer, type it in, and plunge the bead.
  4. Wait until the curve is flat (~20 s bare, longer sleeved). Stop, then Download CSV. Repeat for the next run.
